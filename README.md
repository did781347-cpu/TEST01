# 404 스케줄러 사이트 — 설정 가이드

구글 시트 데이터를 자동으로 불러와서 보여주는 정적 사이트입니다.
**시트에서 값을 수정하면 사이트에도 그대로 반영**됩니다 (새로고침 시).

## 1. 구글 시트 공유 설정
시트 우측 상단 "공유" → 일반 액세스를 **"링크가 있는 모든 사용자" + "뷰어"** 로 설정하세요.
(편집 권한은 시트 자체 공유 설정에서 별도로 관리하시면 됩니다. 이건 사이트가 "읽기"만 할 수 있게 하는 설정이에요.)

## 2. script.js 상단 CONFIG 수정
```js
const CONFIG = {
  SHEET_ID: "여기에_시트ID",
  SCHEDULE_GID: "일정탭_gid",
  GAMES_GID: "게임아카이브탭_gid",
  TODO_GID: "할일메모탭_gid",
};
```
- `SHEET_ID`: 시트 주소 `.../d/이부분/edit` 에서 이 부분
- 각 `GID`: 해당 탭을 클릭했을 때 주소 끝 `#gid=숫자`

## 3. 시트 탭 컬럼 규격

**일정표 탭** (1행은 헤더로 비워두고 2행부터 데이터)
| A: date | B: title | C: tag |
|---|---|---|
| 2026-09-15 | 방송 20:00 | yellow |

tag는 `yellow / blue / red / green / gray` 중 하나 (색깔 태그).

**게임 아카이브 탭** (스팀 리뷰 느낌 — 별점 4점 이상이면 자동으로 "추천", 미만이면 "비추천" 뱃지)
| A: title | B: rating(1~5) | C: note | D: tag(옵션) |
|---|---|---|---|
| 디트로이트 비컴 휴먼 | 5 | 엔딩 8개 중 6개 봄. 감정선 미쳤다. | 어드벤처 |

D열(tag)은 장르 등 자유 텍스트, 비워둬도 됨. 추천/비추천 기준(4점)은 `script.js`의 `RECOMMEND_THRESHOLD`에서 바꿀 수 있어요.

**할일 메모 탭**
A열에 한 줄에 하나씩 할일을 적으면 그대로 메모장에 나열됩니다.

## 4. GitHub Pages에 올리기
1. 새 저장소 생성 → 이 폴더(index.html, style.css, script.js) 전체 업로드
2. 저장소 Settings → Pages → Source를 main 브랜치로 설정
3. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 으로 접속 가능

## 참고
- 사이트 자체는 읽기 전용입니다. 수정은 항상 구글 시트에서 하시면 됩니다.
- 시트가 비공개거나 gid가 틀리면 화면에 "STATUS: LOAD_ERROR" 또는 "불러오지 못했습니다"가 뜹니다.
